### 🔹 Modelo Complejo de San Fernando, Chile

Este modelo macroscópico utiliza la red vial real de San Fernando para simular condiciones de tráfico en escenarios críticos, como:

- Cierres temporales de calles  
- Congestión en horas punta  
- Intervenciones urbanas  
- Eventos masivos como ferias o desvíos  

La animación muestra cómo evoluciona el flujo vehicular ante un escenario con feria instalada, afectando la movilidad en las arterias principales.
